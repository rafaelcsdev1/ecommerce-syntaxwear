# Syntaxwear

Syntaxwear is a modern and stylish e-commerce landing page template for a sneaker store. This project was created to showcase a clean and attractive design for online stores.

## 💻 Live Demo

You can view the live demo of the project [here](https://syntaxwear.vercel.app/).

## ✨ Features

- **Clean and Modern Design:** A visually appealing layout that highlights the products.
- **Responsive:** The layout is optimized for different screen sizes, from mobile devices to desktops.
- **CSS Variables:** The project uses CSS variables for easy customization of colors, fonts, and other properties.
- **Component-Based CSS:** The CSS is organized into components, making it easy to maintain and extend.
